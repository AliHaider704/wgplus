### What's New in v2.0.3

- **Sovereign 24/7 Sensor Engine & 0ms Instant Wake**: Keeps tunnels warm via proactive 115s background rekeys while resting at 0% CPU whenever OS internet is offline, pre-warms `tgnet` on Android screen-on/unlock and Windows Modern Standby display-on (`GUID_CONSOLE_DISPLAY_STATE`), disables Windows 11 EcoQoS throttling for the background tunnel, eliminates the 1-2s "Waiting for network" wake delay on verified hot tunnels, and recovers cleanly from 6h+ deep sleep.
- **Dynamic Nested-VPN & Link MTU Calibration**: Automatically clamps live inner MTU to `1200` when running inside an outer VPN (`tun0` / Wintun) without restarting sockets, calibrates `1280..1420` paths via in-tunnel `DF=1` ICMP probes (honoring WARP `1280` cap), and rotates unhandshaked Cloudflare WARP endpoints across ports `2408 -> 4500 -> 500 -> 1701`.
- **Explicit Client Certificate Trust (Android)**: Replaces silent TOFU with `12` verified official client signing certificates (Google Play, Telegram Direct/Web/Beta, Plus Messenger, Telegram X, Nicegram, Telegraph, Nekogram, Nagram, exteraGram, Cherrygram, OctoGram, Forkgram) plus an explicit in-app Approve/Reject banner for custom LSPatch rebuilds, and returns daemon auth tokens strictly via Binder `Bundle`.
- **Offline Ed25519 Signed Windows Updates & Loopback Guard**: Adds offline dual-key Ed25519 signature verification (`SHA256SUMS-windows.txt.sig`) and anti-downgrade checks to Windows self-updates, plus word-bounded publisher checks, strict `WindowsApps` prefix validation, and SHA-256 EXE caching in Process Guard.
- **VoIP & Multi-Client Reliability**: Fixes HyperOS 2.0 loopback call routing, accepts multi-profile credentials seamlessly across shared local hubs (`SetSocksExtraPasswords`), and converges duplicate clients onto canonical port `48729`.


### [AR] ما الجديد في v2.0.3

- **منظومة المستشعرات السيادية 24/7 والفتح الفوري (`0ms`)**: يُبقي النفق ساخنًا بتجديد استباقي كل 115 ثانية في الخلفية مع سبات كامل `0% CPU` عند انقطاع الإنترنت، ويستبق الاتصال فور إضاءة الشاشة على أندرويد وويندوز (`GUID_CONSOLE_DISPLAY_STATE`)، ويعطّل خنق الطاقة `EcoQoS` على ويندوز 11، ويلغي تأخير «في انتظار الشبكة» عند فتح تيليجرام مع تعافٍ تلقائي بعد النوم الطويل لأكثر من 6 ساعات.
- **معايرة MTU التلقائية والنفق المتداخل**: يضبط الحد الأقصى للحزمة تلقائيًا عند `1200` فوق شبكات الـ VPN الخارجية دون قطع الاتصالات، ويعاير المسار (`1280..1420`) عبر مجسّات `DF=1` مع احترام سقف WARP (`1280`)، ويدوّر منافذ Cloudflare WARP تلقائيًا (`2408 -> 4500 -> 500 -> 1701`) عند تعذر المصافحة.
- **اعتماد الشهادات الصريح لنسخ تيليجرام (أندرويد)**: استبدال القبول الصامت بـ `12` بصمة توقيع رسمية موثقة (متجر بلاي، الموقع الرسمي وبيتا، Plus Messenger، Telegram X، Nicegram، Telegraph، Nekogram، Nagram، exteraGram، Cherrygram، OctoGram، Forkgram) مع بطاقة موافقة أو رفض صريحة للنسخ المعدلة بـ LSPatch، وتسليم رمز التحكم بالـ daemon عبر Binder حصرًا دون تمريره في أوامر التشغيل.
- **توقيع Ed25519 أوفلاين لتحديثات ويندوز وتحصين الحارس المحلي**: التحقق المزدوج بتوقيع Ed25519 (`SHA256SUMS-windows.txt.sig`) ومنع الرجوع لإصدار أقدم عند التحديث التلقائي، وتشديد فحص الناشرين ومسارات `WindowsApps` وذاكرة بصمة SHA-256 في حارس العمليات.
- **استقرار المكالمات وتعدد النسخ**: إصلاح مسار مكالمات HyperOS 2.0، ومزامنة كلمات مرور الحسابات والنسخ متعددة العملاء داخل النفق المشترك (`SetSocksExtraPasswords`)، وتوحيد النسخ المكررة على المنفذ الأساسي `48729`.
