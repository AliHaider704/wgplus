### What's New in v2.0.0

- **Multiple Telegram copies (Android & Windows)**: every installed Telegram copy gets its own tunnel label, so several accounts and copies work side by side.
- **Windows: update in place**: new versions replace the old file directly. No need to delete the old copy and move the new one.
- **Windows: calls in administrator mode, remembered**: the "Restart as Administrator (Fix Calls)" button now relaunches correctly, shows only when calls are not working, and the app can always start as administrator after one approval.
- **Opt-in error reports**: off by default. When enabled (or when you tap Send) a sanitized report goes to the project's Cloud Firestore. See docs/PRIVACY.md.
- **Call watchdog (Android)**: detects calls that connect without audio/video and reports them automatically if reporting is enabled. Includes scripts/android-call-check.sh for self-checks.
- **Stability**: fixes for the 9-hour sleep drop and Xiaomi tunnel flaps.
- **3-tier QA**: CI, Firebase Test Lab on real devices, and on-device checks. See docs/QA_PIPELINE.md.


### [AR] ما الجديد في v2.0.0

- **عدة نسخ من تيليجرام (أندرويد وويندوز)**: كل نسخة مثبتة من تيليجرام تحصل على تسمية خاصة بها داخل النفق، فتعمل عدة حسابات ونسخ جنباً إلى جنب.
- **ويندوز: التحديث فوق النسخة القديمة**: النسخة الجديدة تحل مكان القديمة مباشرة، بدون حذف القديمة أو نقل الجديدة.
- **ويندوز: وضع المسؤول للمكالمات ويُحفظ**: زر "Restart as Administrator (Fix Calls)" صار يعيد التشغيل بشكل صحيح، ويظهر فقط عندما لا تعمل المكالمات، ويمكن تشغيل التطبيق دائماً كمسؤول بعد موافقة واحدة.
- **إرسال الأخطاء اختياري**: مطفأ افتراضياً. عند تفعيله، أو عند الضغط على زر الإرسال، يُرسل تقرير منظّف من البيانات الشخصية إلى قاعدة Cloud Firestore الخاصة بالمشروع. التفاصيل في docs/PRIVACY.md.
- **مراقب المكالمات (أندرويد)**: يكتشف المكالمات التي تتصل بدون صوت أو صورة، ويبلّغ عنها تلقائياً إذا كان الإرسال مفعلاً. مع سكربت فحص ذاتي scripts/android-call-check.sh.
- **الاستقرار**: إصلاح انقطاع النفق بعد النوم الطويل (9 ساعات) وتذبذب النفق على أجهزة شاومي.
- **فحص بثلاث طبقات**: فحص تلقائي، وفحص على أجهزة حقيقية في السحابة، وفحص على الجهاز. التفاصيل في docs/QA_PIPELINE.md.
