# FAQ

**Multiple Telegram copies?** Supported on Android and Windows; each copy gets its own tunnel label.

**Why administrator on Windows?** Calls need the Wintun adapter. Approve once; the choice is saved.

**Updating?** Windows updates in place over the existing file. Android: install over the old APK.

**SmartScreen warning?** Expected for new unsigned-reputation builds. Verify the file with `SHA256SUMS` from the release.

**Reporting bugs?** Use the in-app Send Diagnostics button, then open an issue.
